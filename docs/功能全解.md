## 一、表面总览（重组后：12 工具 / 53 action）

| 工具 | action | 定位 | 前置 / 依赖 |
|---|---|---|---|
| **`video_guide`** | `overview` `playbook` `rules` `tool` `action` | 按需读取的完整能力目录：参数必填、返回值、耗时、陷阱、示例、推荐流程 | 无（纯计算） |
| **`video_env`** | `probe` `presets` `scan` | 机器与素材的**只读事实**：ffmpeg 是否可用、画布预设、素材清单（近重复标注不删除） | 无 |
| **`video_setup`** | `install_ffmpeg` `install_audio` `install_matte` | **装/卸**外部件（ffmpeg、YAMNet、U²-Net） | 网络；几百 MB 磁盘 |
| **`video_plan`** | `check` `duration` `fields` `diagnose` | `plan.json` 的确定性一半：校验、精确时长、字段速查、客观诊断 | 无 |
| **`video_narrate`** | `synthesize` `to_cues` `srt_write` `srt_read` `layout` `transcribe` | 配音与字幕：Edge TTS 逐词时间戳 → 字幕条 → SRT → 烧录样式；转写已有音视频 | `synthesize` 需网络；`transcribe` 需宿主语音服务 |
| **`video_analyze`** | `sample_frames` `audio_events` `audio_status` `matte` `matte_status` | 看素材里到底有什么：自适应抽帧、声学事件、单帧抠像 | ffmpeg；`audio_events` 需 `install_audio`；`matte` 需 `install_matte` + 共享运行时 |
| **`video_gen`** | `models` `generate` `image_models` `image` | 字节 Seedance/Seedream 云端生成（**唯一非确定性**工具） | `ARK_API_KEY`、网络、按次计费 |
| **`video_render`** | `scene` `assemble` `finalize` `deliver` `build` | ffmpeg 执行层：单镜头 → 拼接 → 混音/响度/字幕 → 交付物 | ffmpeg + 计划引用的全部素材 |
| **`video_inspect`** | `verify` `media` | 媒体事实、成片对计划的**冒烟验证** | ffprobe |
| **`video_qc`** | `cases` `check` `structure` `picture` | 成片**验收套件**：28 条命名用例，逐条给期望/实测/判定 | ffprobe、ffmpeg 解码 |
| **`video_audio_build`** | `tone` `assemble` `restore` `record` | 造与修声音：参数全指定的测试信号、采样级拼轨、显式修复链、定时录音 | ffmpeg；`record` 需采集设备 |
| **`video_audio_measure`** | `identify` `speech_map` `loudness` `levels` `integrity` `sync` `noise` `devices` | 量声音：声明 vs 实际、语音/静音图、EBU R128、采样域削波、帧链完整性、双轨偏移与漂移、噪声底、设备枚举 | ffmpeg |

**边界**（重组前后一致，逐条由 guide 的 `rules.divisionOfLabour` 重申）：插件只执行不决策——不选镜头、不定顺序、不定节奏、不写文案；没有「一键出片」动作，编排是调用方的职责。

## 三、确定性核心（`src/core/`）模块地图

| 模块 | 职责（取自模块头注释） |
|---|---|
| `plan.mjs` | 编辑计划：schema、校验、时长算术。`plan.json` 是 DSH 与本插件之间唯一的契约 |
| `scene.mjs` | 把一个镜头规范化为统一中间片段——整条流水线的支点（画布/帧率/像素格式/时间基/音轨） |
| `filter.mjs` | 滤镜图构造：纯计算无 I/O，把声明的意图映射到精确的 ffmpeg 滤镜语法 |
| `assemble.mjs` | 把规范化片段拼成时间线：无转场走 concat，有转场走单张 xfade 图 |
| `finalize.mjs` | 唯一一次成片重编码：混音、响度归一、字幕 |
| `pipeline.mjs` | 整条渲染的分段导出，让失败可归因 |
| `deliver.mjs` | 交付：封面帧、缩略图总览、验收报告 |
| `probe.mjs` / `ffmpeg.mjs` | ffprobe 结果结构化；所有媒体操作统一的进程运行与超时/输出预算 |
| `env.mjs` / `install.mjs` | 外部工具发现与 ffmpeg 供应 |
| `materials.mjs` | 素材清单与近重复标注（只标注不删除） |
| `sampling.mjs` | 自适应抽帧：判断**哪一帧值得看** |
| `matte.mjs` / `matte-install.mjs` | 学习式抠像（U²-Net）；模型供应与共享运行时 |
| `audio-build.mjs` | 有目的地造声音：测试信号与采样级时间线 |
| `audio-measure.mjs` | 让 ffmpeg 量什么，以及把它的散文解析回数字 |
| `audio-signal.mjs` | 解码 PCM 上的纯信号算术（无 ffmpeg、无时钟） |
| `audio-events.mjs` | 声学事件检测：视频**听起来**是什么，而非说了什么 |
| `audio-restore.mjs` | 修复即显式链，并用测量证明它做了什么 |
| `audio-record.mjs` | 采集：列出设备、录固定秒数、测量收到的内容 |
| `audio-integrity.mjs` | 文件是否完整：帧链走查与窄缺口修复 |
| `audio-install.mjs` | 声学事件检测的供应（模型 + WASM 运行时） |
| `tts.mjs` | Edge 朗读服务的旁白合成（无需 Key，逐词时间戳） |
| `srt.mjs` | 字幕几何：逐词时间戳 → 字幕条，以及 SRT 序列化/解析（纯计算） |
| `transcribe.mjs` | 为宿主的语音识别器准备音频并驱动它 |
| `qc.mjs` | 质量检查：成片必须满足的用例清单，确定性判定 |
| `ark.mjs` | 火山方舟视频生成适配器（刻意不做多厂商抽象） |
| `ws.mjs` / `proxy.mjs` | 最小 WebSocket 客户端；经系统代理访问网络 |
| `render.mjs` | **与视频无关**：抓取客户端渲染页面（HTTP GET + 渲染） |
| `index.mjs` | 确定性核心的公开出口（不依赖 DSH） |

- **已迁出**：
  - **桌面自动化**（`desktop.ps1`、`interception-*.ps1`、`driver-setup.ps1`、`src/core/automation.mjs`、`components/vhfkey/`、`vendor/interception/`）整体搬到独立插件 **`dsh-computer-use`**（`C:\Users\Admin\Documents\GitHub\dsh-computer-use`，工具族 `computer_*`）。本插件现在不含任何鼠标、键盘、桌面截图能力，`video_env {action:"probe"}` 也不再报告输入通道、更不会移动指针。
