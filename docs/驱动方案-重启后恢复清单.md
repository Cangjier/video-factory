## 已改好的代码（重启不影响）

| 文件 | 作用 |
| --- | --- |
| `src/bin/interception-probe.ps1` | API 可达性与结构体尺寸自检 |
| `src/bin/interception-input.ps1` | `probe`/`move`/`click`/`point`，走驱动 |
| `src/bin/driver-setup.ps1` | 安装 + 验证 + 回滚提示 |
| `src/bin/ocr.ps1` | Windows 自带 OCR，中文带坐标，~150ms/屏 |
| `src/bin/desktop.ps1` | 截图 / 窗口枚举 / 焦点断言 / SendInput 路径 |
| `src/core/automation.mjs` | `findText` / `clickText` / `clickClient` / 坐标换算 |

**技术要点**：驱动用 0..65535 归一化绝对坐标，`interception-input.ps1` 内已按虚拟桌面
尺寸换算，调用方仍用屏幕像素。`MouseStroke` 封送大小必须是 **20 字节**、`KeyStroke`
**8 字节**，脚本在发送任何事件前会断言，因为尺寸错了会让输入静默失效。

**已验证可用**（上一轮）：OCR 中文识别与整行包围盒、按窗口截图、真实光标移动、
SendInput 文字与组合键、窗口枚举、屏幕↔client 换算（误差 0）。
**没打通的**：SendInput 的点击无法激活浏览器按钮。
